# Practica 4 - Diagnostico de Enfermedades

## Base de conocimiento

### Hechos

- **Gripe**
  - Tos
  - Dolor de cabeza
- **Covid**
  - Fiebre
  - Tos
  - Cansancio
  - Perdida del olfato
- **Migraña**
  - Dolor de cabeza
  - Nauseas
- **Resfriado**
  - Congestión nasal
  - Fiebre
  - Tos

### Reglas

- Si tienes todos los síntomas -> tienes una enfermedad
- Si tienes tos y dolor de cabeza -> gripe
- Si tienes fiebre, tos, cansancio y perdida del olfato -> Covid
- Si tienes dolor de cabeza y nauseas -> Migraña
- Si tienes congestión nasal, fiebre y tos -> Resfriado
