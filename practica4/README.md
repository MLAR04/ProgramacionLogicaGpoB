# Practica 4
### Con la base de conocimiento generada en clase, sobre enfermedades, los síntomas y las reglas. Desarrolla el motor de inferencia en código en Python  que diagnostique la enfermedad con base en los síntomas.

## Enfermedades (Hechos)
- Gripe -> Tos, Dolor de cabeza
- Covid -> Fiebre, Tos, Cansancio, Perdida del olfato
- Migraña -> Dolor de cabeza, Nauseas
- Resfriado -> Congestión nasal, Fiebre, Tos

## Reglas
- Si tienes tos y dolor de cabeza entonces tienes Gripe
- Si tienenes fiebre, tos, cansancio y perdida del olfato entonces tienes Covid
- Si tienes dolor de cabeza y nauseas entonces tienes Migraña
- Si tienes congestión nasal, fiebre y tos entonces tienes Resfriado
