# Base de Conocimiento (BC)

**Gripe:** tos y dolor de cabeza  
**Covid:** fiebre, tos, cansancio, pérdida del olfato  
**Migraña:** dolor de cabeza, náuseas  
**Resfriado:** congestión nasal, fiebre y tos

## Hechos

Gripe ← tos ∧ dolor de cabeza  
Covid ← fiebre ∧ tos ∧ cansancio ∧ pérdida del olfato  
Migraña ← dolor de cabeza ∧ náuseas  
Resfriado ← congestión nasal ∧ fiebre ∧ tos

## Ley

SI TIENES TODOS LOS SÍNTOMAS → TIENES UNA ENFERMEDAD

## Ejemplo

SI TIENES TOS Y DOLOR DE CABEZA → GRIPE
