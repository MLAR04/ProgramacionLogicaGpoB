Regla General: Si tienes todos los síntomas listados para una enfermedad, tienes esa enfermedad.

Gripe: Si tienes tos y dolor de cabeza → Gripe

Covid: Si tienes fiebre, tos, cansancio y pérdida del olfato → Covid

Migraña: Si tienes dolor de cabeza y náuseas → Migraña

Resfriado: Si tienes congestión nasal, fiebre y tos → Resfriado
