## Diagnostico de enfermedades

### Hechos
- **Gripe**: Tos y dolor de cabeza.
- **Covid**: fiebre, tos, cansancio y pérdida del olfato.
- **migraña**: dolor de cabeza, náuseas.
- **Resfriado**: congestión nasal, fiebre y tos.

### Reglas
- Si tienes tos y dolor de cabeza -> tienes gripa.
- Si tienes fiebre, tos, cansancio y pérdida del olfato -> tienes covid.
- Si tienes dolor de cabeza, náuseas -> tienes migraña.
- Si tienes congestión nasal, fiebre y tos -> tienes resfriado.
- Si los sintomas no coinciden con ninguna enfermedad -> no se puede determinar la enfermedad.
