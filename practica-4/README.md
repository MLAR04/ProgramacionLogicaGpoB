# SISTEMA DE DETECCIÓN DE ENFERMEDADES COMÚNES

## ------------------- BASE DE CONOCIMIENTOS ----------------------

Gripe: dolor de cabeza, tos.
Covid-19: fiebre, tos, cansancio.
Migraña: dolor de cabeza, nauseas.
Resfriado: congestion nasal, fiebre, tos.

## HECHOS:

Una persona puede estar enfermo.
Una enfermedad tiene sintomas.


## REGLAS:
- Si tienes al menos 2 síntomas -> tienes una enfermedad.
- Si tienes todos los síntomas -> tienes una enfermedad.
