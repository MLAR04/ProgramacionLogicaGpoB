# Práctica #3

Con la base de conocimiento generada en clase, sobre enfermedades, los síntomas y las reglas. Desarrolla el motor de inferencia en código en Python  que diagnostique la enfermedad con base en los síntomas.

## Base de Conocimiento

### Hechos
- Gripe (Tos y Dolor de cabeza)
- Covid (Fiebre, tos, cansancio, perdida de olfato)
- Migraña (Dolor de cabeza y nauseas)
- Resfriado (Congestión nasal, fiebre y tos)

### Reglas
- Si tienes todos los sintomas ENTONCES tienes una enfermedad
