# Base de conocimiento sobre el sistema de diagnostico de enfermedades comunes

Este sistema funciona para diagnosticar a traves de leyes y hechos enfermedades comunes con los sintomas ingresados por el usuario

## Hechos 

**Gripe** = -tos
            -dolor de cabeza

**Covid** = -fiebre
            -tos
            -cansancio
            -perdida del olfato

**Migraña** = -dolor de cabeza
              -nauseas

**Resfriado** = -congestion nasal
                -fiebre
                -tos


# Leyes
1. Si los sintomas ingresados por el usuario coinciden exactamente con los sintomas de la enfermedad, entonces se diagnostica esa enfermedad

2. Si el usuario tiene mas sintomas de los que corresponden a una enfermedad, entonces no se puede diagnosticar
